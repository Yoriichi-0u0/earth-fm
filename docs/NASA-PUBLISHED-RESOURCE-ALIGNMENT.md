# TerraJuke and the published NASA challenge resources

Verified on November 13, 2026 at 18:05 MYT against the live Space Apps challenge response. Research baseline [`27c9317`](https://github.com/Yoriichi-0u0/earth-fm/commit/27c9317aa199f6d3ec95b3ce00d08e54a9ca55c1). **Keep Climate Spiral A/B as the flagship.** NASA's challenge links to its EIC Content Database, which links through Climate Vital Signs to the same SVS 5190 visualization used by Side A. NASA identifies GISTEMP v4 as the visualization's underlying data family. Side B uses a pinned version of that dataset for a separately explained melody. The strongest demo is one visit to the player that shows how each side produces its sound. ## What the challenge says

The Details tab asks for an Earth jukebox that connects EIC visual frames with dynamically generated sound. The Objectives describe both an interactive tool and a curated collection of original generated audio as possible deliverables. The Resources tab explicitly invites teams to use the EIC collection's videos and images as audio-processing inputs. Its ten other entries provide examples or candidate inputs. No individual entry is marked mandatory. For non-US-government sites, the tab directs participants to follow each site's data-use terms. [Challenge Details](https://www.spaceappschallenge.org/2026/challenges/the-earth-information-jukebox/?tab=details) · [Challenge Resources](https://www.spaceappschallenge.org/2026/challenges/the-earth-information-jukebox/?tab=resources)

| Challenge objective | TerraJuke evidence | Remaining validation |
| --- | --- | --- |
| Pair a specific EIC visual with sound derived from it | The bundled Climate Spiral still traces to SVS 5190 through the challenge-linked EIC gallery. Side A computes sound parameters from its pixels. | Preserve the pinned asset's credit and version. The catalog link is verified and the live file was unavailable for a fresh byte comparison. |
| Generate dynamic sound with an understandable visual-to-sound relationship | Play and Scratch run the visual engine in-browser. A 48-strip scan uses brightness for pitch, RGB for timbre and strip position for stereo pan. The visual readout and Grooveprint expose the selected input and note. | Demonstrate the relationship in one short interaction. Labels and the background contribute to the scan. |
| Make Earth information accessible and engaging | The browser interface supports a keyboard path to playback, silent inspection, a separate audition and reduced motion. The measurement side gives units and the historical reference. | Test blind or low-vision use with a native screen reader, first-time understanding, and listening quality on physical devices. [Validation issue](https://github.com/Yoriichi-0u0/earth-fm/issues/7) |
| Explain and credit the source and method | The app records URLs, hashes, baselines and mapping logic. A November asset comparison confirms that reusing the same file URL can produce a different note. | Verify final asset-specific credits and disclosures before submission. Organizers separately advise teams to start project work at the hackathon, so eligibility of the existing prototype and films remains open. [Organizer guidance](https://github.com/nasa/spaceapps/discussions/1827) · [NASA media guidance](https://www.nasa.gov/nasa-brand-center/images-and-media/) |

[NASA GISTEMP](https://data.giss.nasa.gov/gistemp/) · [App mapping](SONIFICATION.md) |

[NASA source](https://svs.gsfc.nasa.gov/5688/) · [Lab provenance](../research/pacific/provenance.json) |

### Climate Spiral version check

The app's October 18 freeze and an archived November 11 NASA download share the same [SVS filename and URL](https://svs.gsfc.nasa.gov/vis/a000000/a005100/a005190/GISTEMP_Spiral_English_degC_2160p60.01402_print.jpg). Both decoded at 1080 × 1080. A November 13 attempt to download the live JPEG timed out, so the archived response supports the version comparison.

| Version | Bytes | SHA-256 |
| --- | ---: | --- |
| October 18 app freeze | 100,355 | `664a669b9f0b8b8093b7c680d50acc73db0da3996ea770f120041456965594a3` |
| November 11 archived download, HTTP 200 | 100,497 | `038243a40cea07cfaae48b102e4b4563fa41ee29ad53e052eb1bf0e7a79eb8c2` |

Chromium 156 decoded both JPEGs. The comparison drew each to the app's 384 × 384 canvas, then used `imageToSequence` and `mapValueToNote` with the production 48-strip and fixed brightness settings. **Strip 31 changed from A3 (220.00 Hz) to G3 (196.00 Hz)**. Both files produced five distinct notes. Brightness differed in 44 strips, and this was the only pitch-band crossing. This comparison establishes a difference in rendered pixels and their mapped pitches. It provides no estimate of a temperature change. Use the October 18 file to reproduce the app and the existing demo.
