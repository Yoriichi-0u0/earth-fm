# Earth FM — NASA visual-resource readiness

Exploratory source and adapter review, **10 November 2026**. Application inspected: `c17301a`; no new asset is ingested and no dataset/mapping is changed. An available NASA download, EIC association, technical compatibility, asset reuse rights and challenge eligibility are separate claims. Unknown challenge details do not block this research.

## What the existing architecture actually supports

| Boundary | Existing implementation | Consequence for another supplied visual |
| --- | --- | --- |
| Curated metadata | [`EarthFrame`](../src/data/frames.ts): ID/title, source/source URL, image URL, kind, credit/date, original URL, mirror URL, optional video URL. [`jukeboxRecords`](../src/data/jukeboxRecords.ts) selects the Home records. | A verified, bundled image fits the visual record path. Preserve real source metadata; use “not supplied” where appropriate. The current type does not provide a scientific raster decoder or a complete rights schema. |
| Browser decoding | [`useVisualTransport`](../src/lib/useVisualTransport.ts) owns an image/video, a 384px-wide aspect-preserving analysis canvas, decoded readiness and pixel reads. Home [`VisualArtwork`](../src/components/JukeboxHome.tsx) displays the existing source separately. | Ordinary browser-decodable stills/video can be assessed locally. Remote canvas reads need origin-clean media/CORS; there is no universal remote-media importer. Same-origin curated assets avoid that particular remote-canvas issue. |
| Pixel-to-sound | [`imageToSequence` / `FrameAudio`](../src/lib/imageSonification.ts), using the existing [`EarthAudio`](../src/lib/audio.ts). Forty-eight strips; weighted displayed sRGB luma → fixed D3–D5 note choices, RGB → harmonic color, position → stereo. | Reuse the mapping. Text, background, embedded credits, legends and borders are also sampled. It does not decode legend values, locate a country, infer forest height or invert a temperature palette. |
| Time and video | At each audio scheduling boundary, the shared transport reads the current decoded frame; UI updates follow the audio event. Movies loop, are muted and play inline. Motion-off defaults to a still in the reviewed capture. | Media currentTime is not automatically a UTC observation time or an exact source frame number. Frame availability, dropped frames and startup vary by browser. Do not promise frame-accurate temporal replay or deterministic future video samples. A visual WAV export captures a snapshot, not the whole evolving movie. |
| Performance, Scratch and Looper | The reviewed manual path is Climate A and Your Record, using [`useFrameInstrument`](../src/lib/useFrameInstrument.ts) and [`useEarthLooper`](../src/lib/useEarthLooper.ts). | Do not claim every future video record gets Scratch/Looper automatically. Define frozen-snapshot identity and replacement/cancellation behavior before extending manual performance to evolving video. Reuse the single-owner/cancellation contracts. |
| Measurement side | [`measurementSequence`](../src/lib/jukeboxData.ts), [`mapData`](../src/lib/symphony.ts), [`climateMapping`](../src/lib/climateMapping.ts) and the Arctic adapter use actual fixed observations. | A new visual does not automatically create a matching measurement track. A quantitative story needs its own verified data, units, baseline, resolution, dates, missing-value rule and an explainable separately reviewed mapping. Do not route new measurements through the temperature profile by default. |
| Grooveprint | [`grooveprint`](../src/lib/grooveprint.ts) is a pure transform of existing decoded strips or reviewed temperature events. Rendered on Climate's 2D record only. | Geometry may later reuse the same decoded input. It must not independently resample the visual or drive the clock. Do not advertise generic engravings on all four records or optional 3D. |

The Legacy [`FrameJukebox`](../src/components/FrameJukebox.tsx) accepts local PNG/JPEG/WebP/GIF/MP4/WebM up to 20 MiB using MIME/size checks. Home Your Record deliberately supports one preflighted PNG/JPEG/WebP with tighter decoded limits and cancellation. Do not silently reuse the broader Legacy picker as a hardened future media importer, or relax Home safeguards to match it. Ordinary TIFF, EXR, GeoTIFF, HDF/netCDF arrays, tiled services, HTML interactives and spatial queries are not current scientific-input adapters.

Official pages below were opened during this review. Catalog descriptions/formats are verified as page metadata, not downloaded/decoded/play-tested new files. File-specific rights, exact bytes and browser/CORS behavior still need checking before ingestion.

A same-named updated download may differ: retain the old hashes and add a new explicit version rather than silently replacing it. EIC association does not establish acceptance of a specific challenge frame. |
| **SVS 5221 sea-level visual** | [Global Mean Sea Level 1993–2023](https://svs.gsfc.nasa.gov/5221/) supplies visual assets, including [this English still](https://svs.gsfc.nasa.gov/vis/a000000/a005200/a005221/seaLevelRise_2024_English.00405_print.jpg); both its “Used as a Source In” section and SVS 14713 identify their relationship. | **Preferred next independent probe**, after source/rights review: one standalone still via the existing pixel path. Being used inside an EIC production does not automatically make every 5221 frame challenge-eligible. Do not match a rendered frame to the project's historical sea-level observations unless revision, dates, units and aggregation are verified. No new scene is implemented here. |
| **SVS 14713 EIC coastal-resilience production** | [Building Coastal Resilience with NASA Data](https://svs.gsfc.nasa.gov/14713/) explicitly describes an EIC-display production and provides 8K/wide video, stills and panels. Its page permits sharing the complete video but warns that some third-party imagery cannot be excised/remixed. | **Do not default to extracting a short clip/frame for sonification.** Inspect the exact asset and restriction with its rights holder/producer; an associated panel is not automatically exempt. The supplied production soundtrack/music also must not be assumed reusable. Large wide movies need a representative local probe, not a new streaming service. |
| **SVS 4950 GEDI forest visual** | [GEDI Forest Height](https://svs.gsfc.nasa.gov/4950/) provides global MP4/WebM/stills, describes the global view's April 2019–April 2020 input and exaggerated height. Different sub-assets have their own dates. | Pixel sonification is plausible with the current adapter. A camera-rendered globe, lighting, labels and height exaggeration prevent treating arbitrary image brightness as canopy height. Quantitative height needs the underlying product/masks/georeferencing; neither EIC use nor challenge eligibility for a selected asset was verified in this review. Defer until after the smallest still probe. |
| **Existing mirror assets** | [`frames.ts`](../src/data/frames.ts), [mirror notes](FRAMES.md) and [hash manifest](../public/frames/provenance.json) pin night lights, the EIC exhibit photo and Untethered GIF/WebM to an attributed non-NASA repository. Moving Earth's poster has [separate provenance](../public/frames/untethered-record-poster.provenance.json). | Already browser-compatible in the app; exact official byte equality, missing dates and complete production credits remain unresolved. An exhibit photo is not environmental raster data. Keep mirror labels; do not upgrade attribution merely because other official NASA pages are now accessible. |
| **Existing Blue Marble** | [Local provenance](../public/frames/observatory-provenance.json) identifies a July 2004 composite and a display derivative used by the optional contextual globe. | Technically an image but not currently a sonified Home record. Its lighting/rotation are illustrative. Do not add it as a fifth record or describe it as current weather just to fill a resource list. |

NASA's [media usage guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/) support educational/informational use with acknowledgment and without implied endorsement, while reserving third-party material's rights. They are not blanket permission for every production element. Keep each asset's exact credits and restrictions; do not use logos or an EIC tag to imply NASA approval of Earth FM.

The [requested official 2026 challenge details page](https://www.spaceappschallenge.org/2026/challenges/the-earth-information-jukebox/?tab=details) could not be retrieved through the web reader in this run. A direct HTTP check returned 200 and the challenge title/navigation, but no readable full statement or resource specification. The supplied NASA EIC landing URL redirected to an Earthdata portal without readable text. These are access limitations, not proof the pages or requirements do not exist. No current frame package, mandatory codec, API, resolution, scoring rule or submission entitlement is inferred. Continue research against the verified source pages; revisit the exact official materials when accessible before claiming compliance or a submission-ready asset set.

## Smallest future asset-intake experiment — not implemented

Prefer one officially supplied, reusable still over a new adapter or catalog. When an actual resource arrives:

1. Record official source page, exact download URL/ID/version, retrieval date/hash/bytes, media dimensions/format, supplied observation period, full credit, embedded/external rights and EIC relationship evidence. Separate observation date from upload/publication date and film time; unknown remains unknown. Keep any quantitative dataset relationship explicit, not implied by juxtaposition.
2. Verify file-specific reuse for the planned derivative/demo. Preserve the original and provenance. If a smaller display/analysis derivative is needed, document its transform/hash and freeze it: lossy re-encoding changes pixel-sonification results. Do not crop scientific labels merely to improve the music. A declared crop would be a new versioned input, not the old source.
3. Inspect dimensions, aspect ratio, decoded memory, codec and actual pixels in an isolated local probe. Current analysis height is proportional to source aspect ratio without a general curated-media height cap. Home's 4096px-edge/12.6MP/8:1 personal-image rules do not automatically guard curated/video files. A 384px-wide copy does not bound native video decoding cost. Reject/prepare oversized or extreme-aspect inputs before registering them.
4. Test origin-clean canvas sampling (including redirects), unsupported format/codec errors, load/decode timeout, source replacement while initializing, cancellation/navigation, motion-off stills, tab hiding, single audio owner and resource cleanup. Current curated transport has general loading/error messages but not the full bounded personal-image admission pipeline. An untested remote resource is not “ready” because its extension looks supported.
5. Reuse `imageToSequence` and the original pitch helpers; show raw pixel input and credit. If temporal exploration is useful, first establish a trustworthy time/frame manifest. No server, account or Supabase expansion is required for one vetted bundled visual.
6. Only if raw quantitative data are supplied, design a separate adapter/mapping review with units, baseline, coverage, uncertainty and missing-data handling. Preserve the distinction between image structure and physical measurement; an arbitrary palette inversion is not a validated retrieval.

**Ready:** a small vetted still can use the current engine; the current curated movie path demonstrates live frame sampling. **Conditional:** asset-specific rights, codecs/CORS, extreme media and time semantics. **Not implemented:** arbitrary scientific rasters, generic frame-sequence ingestion, spatial measurement picking, automatic official-resource discovery or additional Home records. Research uncertainty warrants a small probe, not a product rebuild or an automatic halt of unrelated work.
